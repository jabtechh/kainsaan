# Icon Placeholders

This directory should contain PWA icons:

- `icon-192.png` - 192x192 pixels
- `icon-512.png` - 512x512 pixels

## Creating Icons

You can create icons with your logo/branding. Recommended tools:
- Canva (free templates)
- Figma (design from scratch)
- PWA Asset Generator (https://github.com/elegantapp/pwa-asset-generator)

The icons should feature the "Kain Saan" branding with food-related imagery (fork/spoon, plate, etc.) on a red-to-yellow gradient background matching the theme colors.

For development, you can use placeholder icons from:
- https://via.placeholder.com/192x192?text=KS
- https://via.placeholder.com/512x512?text=KS
